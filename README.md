# Speaking Corner

Speaking activities for English classes: projectable slides, teacher guides (individual, pairs, whole group), saved classes with history, timers and printable cards.

## How it's organised
- `index.html` – the site (generated, don't edit by hand)
- `src/decks.json` – all activities and their cards
- `src/template.html` – layout, styles and app logic
- `img/` – photos for the slides (named after the activity, e.g. `strange-delivery-03.jpg`)
- `print/` – printable PDFs (generated by `src/make_pdfs.py`)

## Updating
Edit `src/decks.json` or `src/template.html`, add photos to `img/`, then run `python3 build.py`.
